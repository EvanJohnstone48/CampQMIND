# ⛰ Motherlode

A simulated mining valley that explains itself. Around 100 bean miners dig, trade, borrow, befriend and form guilds. You play god, and a narrator tells you in plain language what's happening, why, and how sure it is. Built at Camp QMIND as a test bench for the AWARE-NG conversational-intelligence framework.

**Start here:** [docs/ONBOARDING.md](docs/ONBOARDING.md) (get your laptop set up), [SCAFFOLDING.md](SCAFFOLDING.md) (what each folder is for), then [docs/00-vision.md](docs/00-vision.md) (the idea), [docs/TECH.md](docs/TECH.md) (the tools) and your lane in [docs/lanes/](docs/lanes/).
